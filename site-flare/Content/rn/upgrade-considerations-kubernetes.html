Upgrade Considerations in a Kubernetes Environment

MCP Services

The 18.0.1 cache-operator image watches a new resource, mcpservices.gigaspaces.com/v1.

Using SpaceDeck, you can now create new MCP servers that expose various tools. See XAP MCP Tools Overview.

This feature can be disabled by setting MCP_RECONCILER_ENABLED to false. In that case, this CRD is not scanned.
