AI Agent Skills for GigaSpaces

GigaSpaces provides an open-source collection of Agent Skills in the gs-dev-skill repository under the GigaSpaces Professional Services GitHub organization.

Built on the open Agent Skills specification, each skill is a self-contained folder of instructions, references, and field-validated examples that AI coding assistants load on demand for a given task. These skills are built and tested with Claude (Claude.ai and Claude Code) and also work with GitHub Copilot, OpenAI Codex, and other compatible agents. Each skill folder is independent, allowing you to install only the capabilities relevant to your environment.

Skill Overviews

gigaspaces-xap

Provides expert guidance for GigaSpaces XAP Java development, including Space POJOs, querying with SQLQuery, event-driven processing (Polling and Notify containers), colocated task execution (Task, DistributedTask, and DurableTask), space-based remoting, custom aggregators, transactions, Processing Unit design, Spring Boot integration, Maven setup, and OpenTelemetry distributed tracing.

iidr-cdc-operations

Provides field-validated operational guidance for IIDR CDC engines replicating from Oracle sources, covering TLS encryption for IIDR component-to-component traffic, configuring an IIDR Oracle CDC agent to decrypt TDE-encrypted redo logs, and handling source DDL and schema changes safely.

xap-wan

Covers GigaSpaces XAP WAN Gateway architectures and operations: active-passive and active-active multi-site replication, bootstrapping a new site from an existing site's data, selective replication filters, cross-site conflict resolution, and adding or removing gateway targets on a live Space at runtime.

xap-persist

Provides guidance for GigaSpaces XAP external-database persistence, including full Hibernate-backed Mirror service setup, initial load (including custom initial-load queries), fully custom hand-written JDBC persistence, and redolog internals.

xap-upgrade

Outlines a general methodology for planning a GigaSpaces XAP upgrade, featuring a reusable checklist of dependency-compatibility categories (including Spring and Hibernate), deprecated or removed configuration formats, breaking changes, and planned deprecations.

environment-variables-and-manager

Covers configuring GigaSpaces XAP environment variables and the GigaSpaces Manager: the setenv/setenv-overrides mechanism, current versus legacy GS_* variables, key -D system properties, and Manager setup ranging from a local single-instance development setup to a production 3-Manager HA cluster (ports, embedded ZooKeeper configuration, and ZooKeeper TLS).

firewall-and-static-ports

Provides guidance for making a GigaSpaces XAP cluster reachable across a firewall or NAT boundary: disabling multicast, statically pinning listener ports, identifying which ports must cross the network boundary, and configuring LRMI network mapping for NAT.

remote-proxy-connectivity

Offers structured troubleshooting for clients unable to establish a working SpaceProxy to a remote GigaSpaces XAP Space: a triage checklist, locators and groups discovery (GS_LOOKUP_LOCATORS, GS_LOOKUP_GROUPS, and their -D equivalents), diagnosing CannotFindSpaceException and FinderException, smart-externalizable considerations, and behavioral differences between proxies created inside a deployed Processing Unit and standalone clients.

Installation

Each skill folder (for example, gigaspaces-xap/) is a complete, standalone skill containing its SKILL.md file and references/ directory.

Claude.ai

  1. Clone the gs-dev-skill repository, or download it as a ZIP and extract it.

  2. Zip the specific skill folder you want from inside the repository root, so that the archive's top level is the skill folder itself:

    zip -r gigaspaces-xap.zip gigaspaces-xap

  3. In Claude.ai, navigate to Settings > Capabilities > Skills > Upload skill and select the zip file.

  4. Verify the installation by asking a targeted prompt, such as "Write a GigaSpaces @SpaceClass POJO with a routing field" or "How do I set mirror_on_ddl_operation on an IIDR Oracle CDC subscription?"

Claude Code

  1. Clone the gs-dev-skill repository.

  2. Copy or symlink the skill folder you want into your Claude Code skills directory (user-level or project-level).

  3. Test the skill with a relevant GigaSpaces prompt.

Other Compatible Agents (GitHub Copilot, OpenAI Codex, and Others)

Because these skills follow the open Agent Skills format, copy or symlink each skill folder into the directory your agent scans:

Agent Repo-Level (Project) User-Level (All Projects)
GitHub Copilot .github/skills/, .claude/skills/, or .agents/skills/ ~/.copilot/skills/ or ~/.agents/skills/
OpenAI Codex .agents/skills/ ~/.agents/skills/

Using .agents/skills/ works across multiple agents, making it ideal for teams that use more than one tool:

mkdir -p ~/.agents/skills
cp -r gigaspaces-xap ~/.agents/skills/

Installation Notes

  • Install each skill as its own top-level folder: The xap-configurations/ directory only groups related skills and is not a skill itself. Copy each individual skill folder inside it separately (for example, cp -r xap-configurations/firewall-and-static-ports ~/.agents/skills/).

  • Cross-skill references: Some skills reference another skill by name (for example, xap-persist references gigaspaces-xap, and xap-upgrade references xap-persist). Install related skills together for complete coverage.

  • Verify activation: Each agent decides when to load a skill based on its description. Run a quick test prompt after installation to confirm that the skill triggers as expected.

Continuous Evolution and Community Contributions

The gs-dev-skill repository is actively maintained and continuously evolving. We regularly add new skills, expand coverage for additional GigaSpaces capabilities, and refine existing operational guidance.

Customers and community members are welcome to contribute! If you have created a helpful skill, operational runbook, or improvement for GigaSpaces workflows, please open a pull request or submit an issue directly in the repository under GigaSpaces Professional Services on GitHub.
